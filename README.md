🐱 EL GATO UIIA

Un pequeño juego web interactivo en HTML, CSS y JavaScript donde un gato pixel art cobra vida en tu pantalla.

El gato se mueve de forma autónoma, persigue ratones, rebota con los límites de la página y puede ser agarrado con el cursor. Incluye sistema de vida, sonidos y mecánicas simples tipo videojuego.

🎮 Características
🐾 Gato en pixel art animado
🖱️ Se puede arrastrar con el mouse
🤖 Movimiento automático con rebote en bordes
🐭 Aparición aleatoria de ratones
🍽️ El gato persigue y "come" ratones
❤️ Barra de vida dinámica
💀 Sistema de muerte + pantalla de Game Over
🔁 Botón para revivir
🎵 Música de fondo en bucle
🔊 Efectos de sonido (comer y morir)
