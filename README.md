# Gato-UIIA.io
🐱 EL GATO UIIA  Un pequeño juego web interactivo en HTML, CSS y JavaScript donde un gato pixel art cobra vida en tu pantalla.  El gato se mueve de forma autónoma, persigue ratones, rebota con los límites de la página y puede ser agarrado con el cursor. Incluye sistema de vida, sonidos y mecánicas simples tipo videojuego.
